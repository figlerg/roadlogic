# Beamng.tech Integration

A series of utilities to ease working with BeamNG.tech.

## Installation 

Check the compatibility of your environment here: [BeamNGpy Compatibility](https://documentation.beamng.com/api/beamngpy/master/compatibility.html)

Installation: if you are using v38.0 use v38 as extra

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install -e ."[v38]"
```
